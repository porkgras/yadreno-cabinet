# 🚀 Yadreno Cabinet

Веб-кабинет для управления VPN-ключами

## 🌐 Доступ

- **Веб-кабинет:** https://miniapp.bedalagavpn.mooo.com
- **API Документация:** https://miniapp.bedalagavpn.mooo.com/docs

## 📱 Как войти

1. Нажмите кнопку **"Войти через Telegram"**
2. Подтвердите вход в приложении Telegram
3. Готово! Вы в кабинете

## 🎯 Что можно делать

- 📊 Смотреть статистику использования
- 🔑 Создавать и управлять VPN-ключами
- 💳 Пополнять баланс
- 👥 Приглашать друзей и получать бонусы
